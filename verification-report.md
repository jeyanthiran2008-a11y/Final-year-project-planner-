# Verification Report

## Purpose
Record whether generated or tool-assisted content is accurate, relevant, current, and safe to use.

## Verification procedure
1. Identify every factual claim, number, citation, recommendation, and technical instruction.
2. Trace it to an original, reliable source or a real project artifact.
3. Check dates, versions, scope, and whether the source actually supports the claim.
4. Test code and workflows in the intended browser/device.
5. Record errors, corrections, and unresolved uncertainties.
6. Have a teammate or supervisor review high-impact claims.
