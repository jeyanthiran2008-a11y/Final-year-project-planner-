# Project Readiness and Report-Quality Checklist

## Project readiness
- [ ] Target audience is defined.
- [ ] Problem is specific and evidence-based.
- [ ] Objectives are measurable.
- [ ] Scope and exclusions are documented.
- [ ] Candidate ideas were scored using agreed criteria.
- [ ] Feasibility assumptions are written down.
- [ ] Risks have mitigations and owners.
- [ ] Milestones have dates, owners, and deliverables.
- [ ] Supervisor feedback is recorded.

## Research quality
- [ ] At least two AI/research tools were actually evaluated and documented.
- [ ] University guidelines and report template are current.
- [ ] Source log includes reliable primary/original sources.
- [ ] Claims were checked against original sources.
- [ ] Publication details and URLs/DOIs were verified.
- [ ] AI-generated references were independently checked.

## Report quality
- [ ] Abstract matches the actual work and results.
- [ ] Introduction explains the problem, objectives, scope, and significance.
- [ ] Literature review compares sources instead of listing summaries.
- [ ] Design includes a diagram and explains decisions.
- [ ] Implementation describes the real code and tools used.
- [ ] Testing includes actual outcomes and evidence.
- [ ] Limitations are stated honestly.
- [ ] Every citation has a matching reference and vice versa.
- [ ] Required citation style and formatting are followed.
- [ ] Grammar, headings, tables, figures, and page numbers are checked.

## Responsible AI
- [ ] AI assistance is disclosed according to college rules.
- [ ] AI text was reviewed, corrected, and rewritten as appropriate.
- [ ] No generated claim or citation is treated as verified without checking.
- [ ] Plagiarism and similarity policy was reviewed.
- [ ] No confidential or sensitive data was pasted into an unapproved service.
- [ ] Final report reflects the team's own understanding and work.
