# Prompt Library — Capstone 39

Use these prompts with an AI/research tool only when permitted by your institution. Save the tool name, date, exact output used, and verification record. Never treat generated citations as automatically valid.

## 1. Compare project ideas
> Act as a project-planning assistant for a beginner CSE team. Compare these ideas using feasibility, data availability, time, technical complexity, social/academic value, and risks. State assumptions and missing information. Do not invent evidence. Return a scorecard and questions we should ask our supervisor. Ideas: [paste ideas].

## 2. Research planning
> Help me create a research plan for [topic]. Suggest search terms and types of reliable sources, prioritizing official documentation and peer-reviewed research. Do not fabricate paper titles, authors, DOIs, or URLs. Mark anything that needs independent searching and verification.

## 3. Source verification
> For each claim below, identify exactly what evidence would be needed to support it. If the supplied source text does not support the claim, say so. Do not infer details beyond the source. Claim: [claim]. Source excerpt/link: [source].

## 4. Report outline from notes
> Organize only the notes below into a draft outline for the [section] of our project report. Preserve uncertainty, do not add facts or results, and mark gaps with [NEEDS EVIDENCE]. Notes: [paste your own notes].

## 5. Weekly status report
> Organize these team notes under completed work, next steps, blockers, decisions, and support needed. Do not assume that planned work is completed. Keep ambiguous items under "Needs clarification." Notes: [paste notes].

## 6. Review for unsupported claims
> Review this draft for claims that need citations, vague statements, unsupported numbers, contradictions, and claims that sound more certain than the evidence permits. Do not rewrite it to hide uncertainty. Return a table of issue, reason, and verification action. Draft: [paste draft].

## 7. Viva practice
> Ask me one question at a time about my own project design, implementation, testing, limitations, and ethics. Wait for my answer, then give feedback and a follow-up question. Do not invent project facts for me.
